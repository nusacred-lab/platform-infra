# Repository instructions

All work in this repository must use English. This includes repository and file
names, code identifiers, comments, documentation, UI text, sample labels, commit
messages, pull request titles/descriptions, and newly authored issue content.

Preserve third-party legal notices, protocol identifiers, external references,
immutable evidence, and historical Git objects when editing them would invalidate
attribution, compatibility, or evidence. Write new explanations in English.
Keep secrets and runtime data out of source control. Follow the existing security
and review controls; this language rule does not waive any required checks.

This persistent preference was requested by the maintainer on 21 October 2026,
before implementation-plan phase P2.
